# 봄펫 — 반려동물 돌봄 인수인계 서비스 랜딩페이지

> 반려동물을 맡길 때, 돌봄 정보는 링크 하나로. 맡긴 뒤에도 완료 체크로 안심하세요.

- **배포 URL**: https://(배포 후 Vercel 주소 입력).vercel.app
- **코드잇 스프린트 미션 5**

## 서비스 소개
봄펫은 여행·출장·외박 등으로 반려동물을 다른 사람에게 맡길 때 쓰는 서비스입니다.

| 구분 | 내용 |
|---|---|
| 문제 | 돌봄 정보가 카톡·전화·사진에 흩어지고, 맡긴 뒤 실제로 했는지 몰라 "밥 줬어?"를 반복해서 묻게 됨 |
| 해결 | 보호자가 돌봄 일정·주의사항을 정리해 링크 하나로 공유 → 돌봄자가 가입 없이 열어 완료 체크 → 보호자가 진행 현황 확인 |
| 타깃 | 최근 1년 내 반려동물을 맡긴 경험이 있고, 맡긴 뒤에도 수행 여부를 다시 확인하는 보호자 |
| CTA | 사전 신청(이메일 등록) |

## 기술 스택
- Next.js (App Router), TypeScript
- Tailwind CSS v4
- shadcn/ui (Button, Input, Badge)
- lucide-react
- 배포: Vercel

## 페이지 구성
`히어로 → 문제 → 사용 방법(해결) → 직접 체험 → 기대효과 → 사전 신청(CTA) → 푸터`

## 구현한 인터랙션
1. **모바일 메뉴 토글** — 햄버거 버튼으로 메뉴 열기/닫기, 메뉴 클릭·ESC로 닫힘
2. **핵심 흐름 체험 데모** — 휴대폰 화면 안에서 직접 눌러보는 3단계
   - ① 보호자: 일정 확인 → `저장하고 링크 생성` → 링크 복사
   - ② 돌봄자: 할 일을 눌러 완료 체크 (현재 시각 기록, 다시 누르면 취소)
   - ③ 보호자: 진행률·완료 시각이 바로 반영되고, 모두 완료되면 완료 화면 표시
   - 링크 생성 전 2단계에 들어가면 "받은 링크가 없어요" 안내 (예외 흐름)
3. **사전 신청 폼** — 빈 값·이메일 형식 검사, 오류 메시지, 신청 완료 피드백
4. **섹션 이동 스크롤** — 메뉴·CTA 클릭 시 해당 섹션으로 부드럽게 이동
5. **스크롤 등장 애니메이션** — 섹션이 화면에 들어올 때 페이드인 (움직임 줄이기 설정 시 비활성)

> 사전 신청 폼은 현재 서버 없이 화면 피드백만 제공하며, 이메일은 저장되지 않습니다.

## 실행 방법
```bash
npm install
npm run dev
```
브라우저에서 http://localhost:3000 을 엽니다.

배포용 빌드 확인:
```bash
npm run build
```
